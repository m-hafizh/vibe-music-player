# Vibe Music Player — v3

## Simple Description
v3 introduces a major UI refresh and adds complete light/dark/system theme support.

## Tech Stack
- Vue 3 + TypeScript
- Vite
- Pinia
- Vue Router 4
- Howler.js
- Tailwind CSS
- VeeValidate
- Appwrite SDK

## UI Design and Styling
- New visual direction across key pages/components
- Light/Dark/System theme mode support
- Tailwind dark variants and transition-focused UI polish
- Improved layout consistency for player and content sections

## Features
- Everything from v2.1
- New UI and interaction polish
- Theme mode store (`light`, `dark`, `system`)
- Better visual responsiveness across pages

## Project Scripts
```bash
yarn install
yarn dev
yarn build
yarn test:unit
yarn lint
```

## Version Note
This release focuses on visual quality and usability while keeping the feature base stable.
