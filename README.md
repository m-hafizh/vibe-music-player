# Vibe Music Player — v3.1

## Simple Description
v3.1 is a stabilization/documentation milestone after the v3 UI refresh.

## Tech Stack
- Vue 3 + TypeScript
- Vite
- Pinia
- Vue Router 4
- Howler.js
- Tailwind CSS
- VeeValidate
- Appwrite SDK

## UI Design and Styling
- Keeps v3's refreshed visual system
- Theme-aware styling preserved
- Minor consistency and documentation improvements

## Features
- Core playback flow (play/pause/seek/next/prev)
- Shuffle/repeat/volume controls
- Keyboard shortcuts
- Search/filter and song management flows
- Added project-level documentation (`DOCUMENTATION.md`)

## Project Scripts
```bash
yarn install
yarn dev
yarn build
yarn test:unit
yarn lint
```

## Version Note
This version emphasizes cleanup and documentation before the playlist-focused expansion in v3.2.
